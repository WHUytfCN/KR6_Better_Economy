# KR6 Better Economy

[简体中文](README.md) | [English](README-en.md)

为《Kingdom Rush 6: Genesis》提供可选的关卡经济调节，让玩家自由尝试更多防御塔和英雄搭配，同时保留原版挑战的选择。

**非官方免费插件，请支持正版游戏。** 插件不包含游戏本体，不解锁付费内容。

## 下载与安装

在本仓库的 **Releases** 页面下载：

- **Setup.exe**：自动查找 Steam 游戏目录，也可点击“浏览…”手动选择。确认后安装即可。
- **portable.zip**：将压缩包中的 `KR6_Better_Economy` 文件夹解压到游戏目录，与 `Kingdom Rush Genesis.exe` 放在同一层。

安装前请先关闭游戏。安装器内置全部文件，无需二次联网下载。
安装目录统一为 **KR6_Better_Economy**，请勿修改文件夹名称。
GitHub 自动提供的 Source code 压缩包是源码；玩家请下载上面的安装器或便携包。

## 启动与设置

1. 打开游戏目录中的 `KR6_Better_Economy` 文件夹。
2. 双击 **Start-Economy.cmd**，通过它启动游戏。
3. 打开游戏齿轮设置，在最后一页进入 **金币控制**。

每次使用插件都需要手动运行启动器。普通 Steam 启动保持原版玩法。

| 设置 | 作用 |
|---|---|
| 全局金币倍率 | 调整关卡收入，卖塔退款不参与 |
| 开局金币倍率 | 原版开局金币 × 全局倍率 × 开局倍率 |
| 敌人赏金倍率 | 原版敌人赏金 × 全局倍率 × 敌人倍率 |
| 召唤物掉落金币 | 为已确认的敌方召唤单位恢复对应普通单位的基础赏金 |

三个倍率范围均为 **×0.75～×1.25**，步长 0.05，默认 ×1.00；召唤奖励默认关闭。
买塔、升级价格和卖塔退款保持原版。设置仅影响后续收入，开局倍率下次开局生效。

敌方召唤援兵、分裂体与阶段变化分别处理；石像鬼倒地和复活不视为召唤。
召唤奖励关闭时保留原版掉钱规则。没有有效基础赏金的特殊单位保持原状。

## 兼容性与升级

- 支持 **Windows 10/11、Steam Windows 构建 kr6-desktop-1.00.072**。
- 游戏文件不匹配时会拒绝安装或启动；游戏更新后请等待适配版本。
- 安装器需要 .NET Framework 4.5 或更高版本；运行插件需要系统 Windows PowerShell。
- 安装器暂不支持符号链接或目录联接。安装目录需要写入权限。
- 安装器未做代码签名，Windows 可能显示未知发布者。请核对下载来源及随附的 SHA256SUMS.txt。
- 手动解压升级前，请备份 `settings.ini`，避免被便携包的默认配置覆盖。

## 停用与卸载

可在设置页停用金币调整。关闭游戏后，直接通过 Steam 启动即可游玩原版。
卸载时先关闭游戏，再删除 `KR6_Better_Economy` 文件夹。需要保留设置时，请先备份 `settings.ini`。

## 问题反馈

本版为公开测试版。部分非击杀奖励的浮动文字可能显示原始金额，请以金币余额变化为准。
请通过 **Issues** 提交问题，并附上游戏版本、关卡及模式、倍率设置、召唤开关、复现步骤和预期/实际结果。
日志位于 `KR6_Better_Economy/logs/plugin.log`，上传前可隐去个人路径。
