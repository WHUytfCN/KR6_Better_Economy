# KR6 Better Economy v0.1.0 — 首个公开测试版

提供可选的关卡经济调节，支持全局、开局、敌人金币倍率和敌方召唤赏金开关。
保留原版战斗、塔价、升级价格与卖塔退款规则。默认三个倍率 ×1.00，召唤奖励关闭。

## 下载

- `KR6_Better_Economy-v0.1.0-Setup.exe`：推荐给玩家，自动查找 Steam 游戏目录并安装；也支持手动选择。
- `KR6_Better_Economy-v0.1.0-portable.zip`：手动解压到游戏目录，保留顶层 KR6_Better_Economy 文件夹。
- `SHA256SUMS.txt`：上述两个文件的 SHA-256。

安装器已内置插件，不需要二次下载。不包含游戏本体，请支持正版。
安装后仍须手动运行 `KR6_Better_Economy/Start-Economy.cmd`，普通 Steam 启动保持原版。
安装目录已统一为 KR6_Better_Economy；升级时优先保留新目录配置，否则导入旧 KR6Economy 配置。

## 适配与限制

- Windows 10/11，Steam 构建 kr6-desktop-1.00.072，游戏文件哈希须匹配。
- 游戏更新后可能需要新的插件适配；本版不会绕过校验。
- 五组核心玩法和字体显示已完成本机实测，跨机器验证仍有限。
- 暗块基础赏金为 0，保持原状；不把石像鬼复活等阶段变化视为召唤。
- 部分非击杀奖励浮动文字可能仍显示原始金额；以余额变化为准。
- 首版安装器未签名。请从此仓库下载并检查文件哈希，不要关闭安全防护。
